# 💦 水弹泡泡岛

一个纯前端单文件的 HTML5 Canvas 闯关小游戏：**键盘 / 触屏 双端兼容**，无构建、无依赖，把 `paopao.html` 直接丢进浏览器就能玩。

> 在涨潮的水底迷宫里，用「水弹」炸开砖墙、诱杀紫色小怪，再钻进解锁的金色水门冲向下一关。手快、眼尖、会绕路，才能活过 120 秒。

---

## ✨ 特性

- **零依赖单文件**：`paopao.html` 内联了全部 CSS / JS，Canvas 逐帧渲染，WebAudio 合成音效（无需任何音频资源）。
- **桌面 + 手机双端**：桌面用键盘，手机/窄屏自动切出摇杆 + 放水弹按钮 + 暂停键，操作说明随之切换。
- **10 个手写迷宫**：从「新手浅滩」到「无尽深潭」，怪物从 2 只逐关增至 11 只。
- **会寻路的小怪**：小怪沿网格 BFS 寻路，会被墙挡住、会绕路追你，还会被水弹顺带炸死。
- **道具系统**：砖墙有几率掉落 加速 / 射程 / 水弹+1 / 爱心 四类补给。
- **内置校验脚本**：`verify.js` 可离线检查 JS 语法与全部地图的可达性。

---

## 🎮 玩法

- 目标是**在倒计时结束前通关**：把本关所有小怪清光 → 金色水门变绿 → 走进去过关。
- 水弹放在脚下，**2.4 秒**引信后十字爆炸（默认 1 格，最长可升到 3 格）。
- 小怪**碰到你**会扣 1 命并原地重生（进度保留），共 3 条命；掉到水花里也扣命。
- 倒计时归零也会掉命，重生后重新开始计满时间。

### 规则要点

| 元素 | 行为 |
|---|---|
| 砖墙 `X` | 水弹可炸开（一次只炸到第一块，不穿墙），有几率掉道具 |
| 实心水墙 `~` | **永久墙**，水弹炸不掉，只能绕路 |
| 金色水门 `B` | 怪物未清光前当实心墙挡路；**全清后变绿，可直接走进过关** |
| 紫色小怪 `M` | 开局按出生点固定刷出，会被墙/水弹挡住并绕路追你 |
| 边界石壁 | 最外圈，水弹射线到此为止 |

> 爆炸射线**沿空地穿透，但碰到第一块可炸墙体就停下**——一次不会炸穿多块墙。

## 🕹 操作

### 桌面（键盘）

| 按键 | 功能 |
|---|---|
| `W A S D` / `↑ ↓ ← →` | 移动 |
| `空格` | 放水弹 |
| `P` | 暂停 / 继续 |
| `回车` | 结束 / 重新开始 |

### 手机（触屏）

- **左下摇杆**：按住拖动移动，只走直路（横或竖，不斜走），偏得越多跑得越快。
- **右下 💧**：按下即在脚下放水弹。
- **右上 ⏸**：暂停 / 继续。
- **点按画布**：开始 / 继续 / 结束后重新开始。

## ▶️ 运行

**直接玩（推荐）**

浏览器打开 `paopao.html` 即可，无需服务器、无需安装。

**离线校验（可选）**

需要先装 [Node.js](https://nodejs.org)：

```bash
node verify.js paopao.html
```

输出 `JS syntax OK` 且 10 张地图全部 `OK` 即代表地图与逻辑无阻塞性错误。

## 🛠 技术说明

- **渲染**：`<canvas>` 560×560，13×13 网格（每格 40px），`requestAnimationFrame` 驱动。
- **移动 / 碰撞**：玩家 28×28 碰撞盒做**整盒**撞墙检测（`boxBlocked`），水门解锁后转为可站立。
- **爆炸**：四向射线 + 连锁水弹；`destroyedCells` 只记录真正被炸毁的格，避免误判。
- **小怪寻路**：网格 BFS（`bfsPath`）+ 追击/巡逻状态机（`CHASE_RANGE=6` 内转追击）。
- **音效**：WebAudio 实时合成（放置 / 爆炸 / 道具 / 过关 / 受击），首次交互解锁音频上下文。
- **双端适配**：`@media (pointer:coarse)` 切换触控 UI；`touch-action:none` + `overscroll-behavior` 锁死滚动与缩放。

## 📝 修改与扩展

- **加关卡**：在 `paopao.html` 的 `MAPS` 数组里追加一段 13×13 的 `rows`（字符 `X ~ B M S .`），然后跑 `node verify.js paopao.html` 校验可达性。
- **调数值**：`TIME_LIMIT`（每关秒数）、`BASE_SPEED`、`BOMB_ARM`（引信）、`MON_SPEED`、`CHASE_RANGE` 等常量集中在文件顶部。
- **怪物数量**：每关怪物数 = 该关 `M` 出生点数量（第 1 关 2 只，逐关 +1）。
